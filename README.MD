# 🤖 AI Supply Chain Copilot

> End-to-end AI Automation project focused on Supply Chain operations.

## 📌 About

The AI Supply Chain Copilot is a portfolio project designed to simulate a real corporate ERP environment enhanced with Artificial Intelligence.

The objective is to demonstrate practical skills in:

- AI Automation
- Python Development
- Data Engineering
- Supply Chain Analytics
- Machine Learning
- Business Intelligence
- ERP Process Automation

Instead of isolated coding exercises, this project reproduces real business scenarios found in logistics, procurement, inventory management and operational planning.

---

# 🎯 Project Goals

The project will progressively evolve into an AI-powered Supply Chain assistant capable of:

- Reading invoices (PDF/XML)
- Extracting structured information automatically
- Building inventory databases
- Calculating Supply Chain KPIs
- Forecasting demand
- Detecting anomalies
- Answering business questions using LLMs
- Assisting operational decision making
